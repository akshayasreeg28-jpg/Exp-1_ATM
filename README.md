# Exp-1 ATM & BANKING SYSTEM

# AIM:
  To design and develop a Software Requirements Specification (SRS) for an ATM and Banking System and represent its functionalities using UML diagrams to understand the system structure, interactions, and workflow.
# SRS (Procedure):
  Identify the functional and non-functional requirements of the ATM and Banking System.
Identify the actors involved, such as Customer, Bank Server, and Administrator.
Define the major functionalities, including:- User authentication using ATM card and PIN.
- Balance enquiry.
- Cash withdrawal.
- Cash deposit.
- Fund transfer.
- Mini statement generation.
- Account management.

Identify the system requirements, including hardware and software requirements.
Design the following six UML diagrams to represent the system:- Use Case Diagram.
- Class Diagram.
- Sequence Diagram.
- Activity Diagram.
- State Chart Diagram.
- Component Diagram.

Analyze the diagrams to understand the interactions between users and the banking system.
